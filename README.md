# Ultima Image Converter (uic)
### Free, Open-Source, and Private Image Conversion Tool
![Ultima Image Converter Icon](/uic_icon.ico)

Ever get tired of having to look online to convert HEIC files from your
IPhone to a standard format like PNG or JPEG? While many cloud services can do this, you never really know how private they are or what they are doing with your images and data.

For this reason, I built `uic`. It is currently a CLI program that can convert nearly any image file or batch of files you give it and convert it to one of its many supported formats (i.e. png, jpeg, webp, avif, tiff, bmp, gif).

This project is still very much a work in progress. If you would like
to contribute feel free to take the source and send in some patches.
I'll check them out if I have the time. You could also make requests
for additions and I might get around to them.

`uic` doesn't track you and all image conversion happens locally 100%
on your machine.
